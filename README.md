# VASUNDHARA DIARY AND FARMS

> **Nature's Land. Modern Dairy. A Better Tomorrow.**
> Modern Dairy Farming | Fresh Milk Production | Sustainable Agriculture | Animal Welfare

A premium, visually stunning, fully responsive 6-page web application for **VASUNDHARA DIARY AND FARMS**, an upcoming modernized dairy farming venture based across **5.5 acres of fertile agricultural land** with an initial livestock capacity of **20 planned Holstein Friesian (HF) and Jersey cattle**.

---

## 🎨 Watermelon UI Design System

Designed strictly following the Watermelon UI brand identity:

- **Deep Forest Green** (`#164D32`): Headers, navigation accents, "Why Choose Us" dark section, and footer.
- **Natural Green** (`#27864B`): Subheadings, badges, organic leaf icons, and borders.
- **Watermelon Red** (`#F04458`): Primary action buttons ("Explore Our Farm →", "Let's Connect", "Send Enquiry →") and focal headline accents.
- **Watermelon Pink** (`#FF7185` / `#FFE4E8`): Category tags, highlight tints, and pastel borders.
- **Soft Cream** (`#FFF9F1`): Organic page body background.
- **Pure White** (`#FFFFFF`): Floating glass navigation bar, stat cards, and modals.
- **Dark Text** (`#26332C`): High-contrast typography with Plus Jakarta Sans and Outfit.

---

## 📖 6-Page Structure

1. **Home (`#home`)**: Floating white rounded navbar, dynamic kinetic headline (*"Where Nature Meets Modern Dairy Farming."*), continuous running ticker ribbon, floating 3-column stats bar (5.5 Acres, 20 Planned Cattle, Modern Dairy Vision), split-screen About section, 5 pastel-pink product cards, curved deep-green Why Choose Vasundhara section, masonry photo gallery, vision & mission cards, and final CTA.
2. **About Us (`#about`)**: Company introduction narrative, 4-step agricultural story, vision & mission, and 6 core values (Quality, Integrity, Animal Welfare, Sustainability, Innovation, Responsibility).
3. **Our Farm (`#farm`)**: 5.5 acres land zoning (fodder, housing, cold chain), Holstein Friesian (HF) & Jersey cattle showcases, 20-cattle planned highlight, and 6 modern infrastructure cards.
4. **Products (`#products`)**: 5 proposed product cards (Fresh Cow Milk, Pasteurized Milk, Curd, Paneer, Traditional Ghee) with "Enquire Now" modal triggers and 4-pillar Quality Commitment section.
5. **Sustainability (`#sustainability`)**: Responsible Animal Care, Sustainable Agriculture, Modern Dairy Management, and 4-Phase Future Roadmap.
6. **Contact Us (`#contact`)**: Farm specifications, contact channels, interactive Google Map modal, and validated inquiry form with reference ID generator and WhatsApp direct connectivity.

## 🚀 Getting Started Locally

### Prerequisites
- Node.js (v18 or higher recommended)
- npm (v9 or higher)

### Installation

```bash
# Clone the repository
git clone https://github.com/6888mayank/Dairy-Farming.git
cd Dairy-Farming

# Install dependencies
npm install

# Start development server
npm run dev
```

The application will be available at `http://localhost:5173/` (or next open port).

### Production Build

```bash
# Build production bundle
npm run build

# Preview build locally
npm run preview
```
